# 固件源码说明

`executor.c` 是当前优化后的算子执行器，`camera_hooks.c` 完成真实相机输入、进度、缓存和实际结果到 OSD 的桥接；对应头文件和 `link.ld` 一同提供。

`legacy/` 中的文件是本版实际编译所需的协议、上传器、平台接口、图调度及后处理源文件。目录名保留其原始组件来源，属于这一套固件的依赖，不是额外可执行版本。仅保留当前构建需要的文件；没有旧 `.o`、旧 BIN 或旧演示程序。

在包根目录运行 `build_firmware.ps1`，或执行 `tools/build_camera_firmware.py --toolchain <工具链bin目录>`，即可完整重建当前固件。修改后的产物需重新验证，不能继承已冻结的板测通过状态。
